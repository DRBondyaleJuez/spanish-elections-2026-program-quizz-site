# Programas 29N

Web para estudiar los programas electorales de las Elecciones Generales del 29/11/2026 y el manual de la mesa electoral: resúmenes por tema, comparador con % de acuerdo y tests.

- 🌐 **Web publicada:** https://drbondyalejuez.github.io/spanish-elections-2026-program-quizz-site/
- Plan: [ROADMAP.md](ROADMAP.md) · Normas del proyecto: [AGENTS.md](AGENTS.md)
- Verla en local: `python tools/serve.py` → http://localhost:8000

Los PDFs de `sources/` son documentos públicos de cada partido y de la Junta Electoral / Ministerio del Interior. Esta web resume lo que dicen, sin dar opinión.
